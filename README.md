# 金額計算アプリ

期ごとに支払額が異なる飲み会・イベントの集金計算をかんたんに行えるツールです。

## 使い方

### 1. 総額を入力する

画面上部の金額をタップすると編集できます。徴収したい総額を入力してください。

### 2. 期を設定する

チップ（タグ）が各期を表しています。

- **＋ 期追加** ボタンで期を追加できます
- `15期` などの期表示をタップすると、期を入力して変更できます
- 各チップの **− / ＋** ボタンで、人数を1人ずつ変更できます
- 左端の **⠿** をドラッグ＆ドロップすると並び替えられます（先頭の期が支払額欄の一番上に表示されます）
- 右端の **×** ボタンで期を削除できます（期が1つだけの場合は削除できません）

### 3. 支払額を調整する

各期のスライダーを動かして、一人あたりの支払額を設定します。

| 期 | 動作 |
|---|---|
| **一番上の期**（緑色） | 総額からほかの期の支払分を引いた残額をもとに、一人あたりの金額を自動計算します |
| **ほかの期**（青色） | スライダーで一人あたりの金額を設定します |

- スライダー右端の **＋** ボタンで上限を 5,000 円 → 10,000 円に拡張できます

### 4. 合計を確認する

画面下部の「支払いサマリー」で確認します。

- **合計一致** ✓：各期の支払総額が設定した総額と一致しています
- **差額あり** ⚠：金額がずれています。青色の期のスライダーや人数、総額を調整してください

### 5. 結果をコピーする

「結果をコピー」ボタンを押すと、期ごとの一人あたり金額をクリップボードにコピーできます。

### 6. フィードバックを送る

画面右上の吹き出しボタンから、改善してほしい点や気づいた点を送れます。お名前の入力は任意です。

---

## ヒント

- **一番上の期は自動計算**：ほかの期の金額を決めると、一番上の期の一人あたり金額が自動で計算されます
- **キーボード操作対応**：スライダーにフォーカスした状態で ← → キーで微調整できます（Shift キーで10倍ステップ）
